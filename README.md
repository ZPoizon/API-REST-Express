# API REST com Express

Este projeto é uma API REST desenvolvida utilizando Node.js, Express e CORS.

O objetivo da atividade é criar uma API que disponibiliza uma rota, retornando a data e a hora atual, além de uma mensagem informando que a API está funcionando.

## Tecnologias utilizadas

- Node.js
- Express
- CORS
- JavaScript
- Git e GitHub
- Render
